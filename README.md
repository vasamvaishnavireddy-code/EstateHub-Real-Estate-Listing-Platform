# EstateHub-Real-Estate-Listing-Platform
EstateHub is a responsive real estate listing platform built with HTML, CSS, and JavaScript. It allows users to search, filter, explore, compare, and save properties, calculate EMI, list properties, and submit inquiries through a clean, professional, and user-friendly interface.

## Features

- 🏠 Property Search and Filtering
- 🔄 Buy / Rent Selection
- 🏢 Property Categories
- 📋 Detailed Property Information
- ❤️ Favorites
- ⚖️ Compare Properties
- 🧮 EMI Calculator
- 🏘️ List Your Property
- 📩 Contact and Inquiry Form
- 📱 Responsive Design
- 💾 LocalStorage Support

## Property Categories

- Apartments
- Houses
- Villas
- Plots
- Commercial Properties

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Font Awesome
- LocalStorage
- Visual Studio Code
- Live Server
